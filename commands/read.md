# 原著导读

要读的文本和位置：**$ARGUMENTS**

没有给出文本时，先看进度里最近的 `readings`；有记录就问学生是否接着读那一部，没有就问学生想读什么，然后停下。

## 1. 找到文本

**原文来源**按以下顺序：
1. **学生自己的 PDF**（首选）。学生给了路径就用；否则在当前文件夹里找文件名与文本名相符的 `.pdf`。找到多个时让学生选。
2. **学生贴进来的文字。**
3. **公版原文**（希腊文、拉丁文、德文原版、文言原典、梵文巴利文原典等）可以凭你的知识引用，但要说明是凭记忆引用，以学生手头的版本为准。

找不到 PDF、学生也没贴文字时，对现代中译本只给出处位置，并请学生把 PDF 放进当前文件夹，或者贴出要读的段落。不要凭记忆复述现代译本的大段译文。

## 2. 读取 PDF

插件自带的脚本只用 macOS 自带组件，不需要安装依赖：

```
osascript -l JavaScript "${CLAUDE_PLUGIN_ROOT}/scripts/pdftext.js" info "<pdf>"
osascript -l JavaScript "${CLAUDE_PLUGIN_ROOT}/scripts/pdftext.js" text "<pdf>" <起始PDF页> <结束PDF页> "<缓存目录>"
osascript -l JavaScript "${CLAUDE_PLUGIN_ROOT}/scripts/pdftext.js" image "<pdf>" <PDF页> "<输出.png>"
```

- `info`：总页数、有没有文字层、页码标签样本。
- `text`：把指定页的文字写到缓存目录，每页一个文件（`p0200.txt`），然后用 Read 读这些文件。扫描版会自动做 OCR；已经处理过的页不会重复处理。一次最多 31 页，带读时一般只取当前要读的 1–3 页。页边的标准页码会写成 `【边码 〔192〕】`，接在对齐的正文行前面。
- `image`：把一页渲染成图片，用 Read 查看。只在 OCR 文字明显有误、而这里的措辞又很关键时使用，例如脚注、希腊文、德文原词。

缓存目录统一用 `.aizhi/texts/<文本标识>/pages/`。

**OCR 的局限**：扫描版会有零星错字，脚注和小字更多。引用时，明显的识别错误直接改正（例如“世裕”改为“世俗”）；拿不准、又关系到理解的字词，用 `image` 看原页，或者向学生说明。

脚本运行失败时（例如不是 macOS），改用 Read 工具直接读 PDF 的对应页；还不行，就请学生贴出段落。

## 3. 第一次读某个 PDF：建索引

如果 `.aizhi/texts/<文本标识>.yaml` 不存在，先建索引：

1. 运行 `info`，确定有没有文字层，以及页码标签和书页的对应关系。
2. 提取前 10–15 页，找到目录，必要时再往后多取几页。
3. 抽一页正文，确认页边印的是哪种标准页码（科学院版、A/B 版、Stephanus、Bekker 等），还是没有。
4. 写入索引文件：

```yaml
id: kant-ak2                       # 文本标识，小写英文或拼音
title: 康德著作全集 第2卷：前批判时期著作Ⅱ（1757–1777）
file: 康德著作全集_第2卷_前批判时期著作Ⅱ（1757-177.pdf
edition: 李秋零主编，中国人民大学出版社
text_layer: false                  # false 表示扫描版，需要 OCR
page_offset: 9                     # PDF 页 = 书页 + page_offset
standard_pagination: 科学院版（Ak.）第 II 卷页码，印在页边，形如〔192〕
contents:                          # 书页；只列到对带读有用的层级
  - title: 证明上帝存在惟一可能的证据（1763）
    page: 71
    sections:
      - { title: 前言, page: 72 }
      - { title: 第一章 考察一 论一般存在, page: 77 }
```

然后用一两句话告诉学生：这是什么版本、扫描版还是文字版、页边有没有标准页码。

已有索引时直接使用，不要重建。

## 4. 定位

把学生给的位置换算成 PDF 页：
- 章节名：查索引的 `contents`。
- 书页：加上 `page_offset`。
- 标准页码（如 Ak. II 192、A19、B59、Stephanus 514a）：先根据索引估计大致在哪几页，提取文字，找到对应的 `【边码】`，再前后调整。
- 学生要“从头读”某部著作：从它的第一页开始。

## 5. 逐段带读

“一段”是一个完整的论证单元，通常是一到几个自然段，不按页机械切分。每一段按下面的顺序带读：

1. **定位**：这段在全书结构中的位置，前面讲到哪里，这段要做什么。注明书页和标准页码。
2. **关键句**：只摘最关键的一两句原文，附页码；其余用转述，学生手里有全文。
3. **论证重构**：写出前提、推论、结论，标明隐含的前提。这段不是论证（例如是定义、例子、对他人观点的转述）时，说明它在论证中起什么作用。
4. **关键概念**：给出原词（德文、希腊文、拉丁文等，凭知识给出时要说明），并说明这个译本的译法是否有值得注意的地方，必要时对照其他译本的译法。
5. **研究性解读**：只在有实质分歧时才写。说明主要的解读分歧和代表学者，没有把握的不要编造。
6. **理解检查**：提一到两个问题，检验学生是否真正读懂了这一段。例如：某个前提从哪里来？某个词在这里是什么意思？这一步推论成立吗？

然后**停下，等学生回答**。学生回答后：
- 简短反馈：哪里对，哪里有偏差，偏差在哪里。
- 学生说“下一段”或答得没问题时，进入下一段。
- 学生可以随时说“跳到……”“停”，或者就这一段提出自己的问题。

保持节奏：每次只带读一段，不要一口气讲完一整章。

## 6. 记录进度

进度文件的格式以进度规范 `${CLAUDE_PLUGIN_ROOT}/skills/progress/SKILL.md` 为准，本次会话还没读过就先用 Read 读一遍。`readings` 条目**只用下面这些字段**，不要自造字段名：

```yaml
readings:
  - text: 证明上帝存在惟一可能的证据      # 正在读的著作名，不是索引的文本标识
    edition: 李秋零主编《康德著作全集》第 2 卷
    file: 康德著作全集_第2卷….pdf         # 学生的 PDF 文件名
    index: .aizhi/texts/kant-ak2.yaml     # 索引文件路径
    section: 第一章 考察一 论一般存在     # 当前章节，取自索引的 contents
    position: Ak. II 72                   # 下一次要读的那一段的起点：标准页码，没有就写书页
    pdf_page: 87                          # 与 position 对应的 PDF 页
    last_read: 2026-10-07
    notes:                                # 列表，每条一件事
      - 已读完开篇方法说明（Ak. II 70–72），理解检查待回答
      - 下一段：一、存在根本不是某一事物的谓词
```

同一部著作只保留一个条目，接着读时更新它，不要新增。

**每带读完一段、提出理解检查问题之后**，立即更新这部文本的 `readings` 条目（`position`、`pdf_page`、`last_read`、`notes`）和 `last_session`，只记位置。这样学生直接关掉会话，`/aizhi:resume` 也能接上。

学生说“停”、或读完一个完整部分时，再做完整更新：
- 更新这部文本的 `readings` 条目，在 `notes` 里写下停在哪个论证、哪里还没读懂。
- 这次读到的关键概念，新增或更新 topic 条目（新概念 mastery 设为 0），并附 1 道复习题，最好是论证重构或原文定位题。
- 学生在理解检查中出现的误解，写入相关 topic 的 `weak_points`。
- 更新 `last_session`，activity 为 `read`。

最后用一句话告诉学生记录了什么，以及下次用 `/aizhi:resume` 会从哪里接着读。
